# Julio Soto Portfolio

Lightweight GitHub Pages portfolio for Julio Soto, positioned as a Senior QA Automation Engineer / SDET who builds reusable automation frameworks and maintainable software.

## Current content strategy

- Keep the site static, fast, and easy to maintain.
- Emphasize engineering impact instead of CV-style tool lists.
- Prioritize five recruiter-relevant projects:
  - QA Selenium Framework
  - QA Playwright Framework
  - QA API Automation
  - Flask ToDo Application
  - QuickSale POS
- Remove historical project detail pages that no longer support the QA Automation / SDET positioning.

## Structure

- `index.html` - Main portfolio page with SEO metadata, experience, grouped skills, selected projects, README backlog notes, and contact information.
- `assets/css/style.css` - Custom styles organized around design tokens and reusable static-site components.
- `assets/js/main.js` - Lightweight navigation, scroll state, and animation initialization.
- `sitemap.xml` - Canonical sitemap for the single-page portfolio.

## Local review

Open `index.html` directly in a browser or serve the folder with any static file server:

```bash
python -m http.server 8000
```
