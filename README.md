# Julio Soto Portfolio

Lightweight personal portfolio for Julio Soto, positioned as a Senior QA Automation Engineer.

## Focus

- QA automation and test strategy
- API, UI, and regression testing
- Accessible and responsive web quality
- Selected historical projects relevant to quality engineering and web delivery

## Structure

- `index.html` - Main portfolio page with SEO metadata and accessible content structure.
- `assets/css/style.css` - Custom styles organized around design tokens and reusable components.
- `assets/js/main.js` - Lightweight navigation, scroll state, and animation initialization.
- `proyecto-*.html` - Detail pages for selected historical projects.

## Local review

Open `index.html` directly in a browser or serve the folder with any static file server.
